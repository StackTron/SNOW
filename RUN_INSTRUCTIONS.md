# 📖 Подробная инструкция: как запустить сайт «Тайный Санта» (бесплатно)

Эта инструкция написана **для полного новичка**. Каждый шаг расписан подробно — просто следуйте по порядку.

---

## 🎯 Что у вас должно получиться в конце

- Работающий сайт на вашем компьютере: `http://localhost:3000`
- Возможность **создавать розыгрыши**, **приглашать участников**, **проводить жеребьёвку**
- Все данные сохраняются в файле `data/santa.sqlite` (ничего не потеряется при перезапуске)

## 📋 Что понадобится

1. **Windows 10/11** (инструкция для Windows)
2. **Интернет** (для скачивания Node.js)
3. **10–15 минут** свободного времени

## 🛠 Шаг 1: Установите Node.js (это «движок» для сайта)

> Node.js — это программа, которая позволяет запускать JavaScript-код на компьютере (не в браузере). Без неё сайт не заработает.

### 1.1 Скачайте установщик

1. Откройте браузер и перейдите на: **https://nodejs.org/ru/**
2. Вы увидите две кнопки. Нажмите на зелёную: **«LTS» (Long Term Support)** — это стабильная версия.
   - На момент написания это **Node.js 22.x** (или новее)
   - Файл скачается как `node-v22.x.x-x64.msi`

### 1.2 Установите Node.js

1. Найдите скачанный файл (обычно в папке **Загрузки / Downloads**) и **дважды кликните** по нему.
2. В открывшемся окне нажимайте **Next** (Далее) до конца:
   - ✅ Принять лицензию → Next
   - ✅ Папка установки (оставьте как есть) → Next
   - ✅ Компоненты (оставьте всё по умолчанию) → Next
   - ✅ **Важно**: поставьте галочку **«Automatically install the necessary tools…»** (автоматически установить нужные инструменты) — это поставит Python и инструменты сборки, если их нет.
   - Install → Finish
3. **Перезагрузите компьютер** (или просто закройте и откройте терминал/командную строку заново).

### 1.3 Проверьте, что Node.js установился

1. Нажмите `Win + R` → введите `cmd` → Enter (откроется чёрное окно — **Командная строка**).
2. Введите по очереди (после каждой нажимайте Enter):

```cmd
node --version
npm --version
```

3. Должно показать что-то вроде:
   ```
   v22.12.0
   10.9.0
   ```
   (версии могут быть другими — главное, чтобы **не было ошибки** «node не является внутренней или внешней командой»).

## 🚀 Шаг 3: Запустите сайт **в первый раз**

### 3.1 Откройте терминал в папке проекта

**Вариант А (самый простой):**
1. В Проводнике зайдите в папку `C:\Users\WIZARD\Desktop\site`
2. В **адресной строке** Проводника (где написан путь) **стереть всё** и написать `cmd` → Enter
   - Откроется командная строка **уже в нужной папке**

**Вариант Б (через меню):**
1. Зажмите `Shift` + **правый клик** по пустому месту в папке `site`
2. Выберите **«Открыть в терминале»** или **«Open PowerShell window here»**

### 3.2 Установите зависимости (делается один раз)

В терминале введите:

```cmd
npm install
```

- Пойдёт скачивание пакетов (у этого проекта зависимостей почти нет, так что быстро).
- В папке появится `node_modules/` — **не удаляйте её**.

### 3.3 Запустите сервер

В том же терминале введите:

```cmd
npm start
```

Вы увидите:
```
> secret-santa-pyatigorsk-2027@1.0.0 start
> node server.mjs

Secret Santa: http://localhost:3000
```

**Не закрывайте это окно!** Сервер работает, пока окно открыто.

### 3.4 Откройте сайт в браузере

1. Откройте любой браузер (Chrome, Edge, Firefox, Яндекс)
2. В адресной строке введите: **`http://localhost:3000`** → Enter
3. Вы увидите главную страницу «Тайный Санта Пятигорск 2027» ❄️

## ✅ Шаг 4: Проверьте, что всё работает (полный цикл)

### 4.1 Создайте аккаунт (организатор)

1. На главной странице нажмите **«Создать аккаунт»** (золотая кнопка)
2. Заполните:
   - Имя: `Иван`
   - Фамилия: `Тестов`
   - Email: `ivan@test.local` (любой, даже несуществующий — письма не уходят)
   - Пароль: `password123` (минимум 8 символов)
   - Повторите пароль
3. Нажмите **«Создать аккаунт →»**
4. **ВАЖНО**: Покажется **Код восстановления** (например, `A1B2C3D4E5`). **Сохраните его!** (скопируйте в блокнот). Без него не восстановите доступ, если забудете пароль. Нажмите «Я сохранил(а) код →».

### 4.2 Создайте розыгрыш (мероприятие)

1. После входа откроется **Личный кабинет** (модальное окно).
2. Нажмите **«+ Новое событие»**.
3. Заполните:
   - Название: `Семейный Тайный Санта 2027`
   - Описание: `Собираемся 31 декабря, бюджет 1000₽`
   - Галочка «Показывать в списке открытых мероприятий» — **оставьте** (чтобы другие могли найти)
4. Нажмите **«Создать и получить ссылку →»**
5. Откроется **панель организатора**. Вы увидите:
   - **Ссылку-приглашение** (кнопка «Скопировать ссылку»)
   - Список участников (пока пустой)
   - Кнопку **«Закрыть регистрацию»** и **«ДЕД МОРОЗ, ВПЕРЁД!»**

### 4.3 Пригласите участника (второй браузер / инкогнито)

Чтобы проверить, как участник присоединяется:

1. Откройте **новое окно в режиме инкогнито** (Ctrl+Shift+N в Chrome/Edge) или **другой браузер**.
2. Перейдите по скопированной ссылке-приглашении (например, `http://localhost:3000/?event=...&invite=...`)
3. Появится страница мероприятия с кнопкой **«Вступить в розыгрыш →»**
4. Нажмите её → предложит войти / зарегистрироваться.
5. Зарегистрируйте **второго пользователя** (другой email: `maria@test.local`, пароль `password123`, сохраните код восстановления).
6. После входа — участник автоматически добавится в розыгрыш.

### 4.4 Проведите жеребьёвку

1. Вернитесь в окно **организатора** (где панель организатора).
2. Теперь в списке участников будет 2 человека.
3. Нажмите **«ДЕД МОРОЗ, ВПЕРЁД! ✦»**
4. Подтвердите в диалоге.
5. **Готово!** Жеребьёвка проведена. У каждого участника в личном кабинете появится: **«В этом году ты стал Тайным Сантой для [Имя Фамилия] 🎁»**

### 4.5 Проверьте чат (анонимная переписка)

1. У организатора и участника в личном кабинете появятся **две чат-комнаты**:
   - «Моя переписка с получателем» — вы пишете своему подопечному
   - «Мой Тайный Санта» — ваш Санта пишет вам
2. Напишите сообщение в любом чате — оно приходит мгновенно (обновление каждые 4 сек).

## 🔄 Как пользоваться сайтом в будущем

### Остановить сервер
- В терминале, где запущен сервер, нажмите **Ctrl + C** → введите `Y` → Enter
- Или просто закройте окно терминала.

### Запустить снова
1. Откройте терминал в папке `C:\Users\WIZARD\Desktop\site` (как в шаге 3.1)
2. Введите `npm start`
3. Откройте `http://localhost:3000`

### Важные файлы, которые НЕЛЬЗЯ удалять
- `data/santa.sqlite` — **вся база данных** (пользователи, мероприятия, участники, чаты, результаты жеребьёвки). Если удалите — всё потеряете.
- `node_modules/` — зависимости (можно удалить, но потом снова `npm install`).

### Бэкап (резервная копия) базы
Перед важными изменениями делайте копию:
```cmd
copy data\santa.sqlite data\santa-backup-%date:~-4%%date:~3,2%%date:~0,2%.sqlite
```
Или просто скопируйте файл `santa.sqlite` в другую папку через Проводник.

## ☁️ Шаг 5: Как запустить сайт в интернете **БЕСПЛАТНО** (чтобы друзья могли зайти по ссылке)

Локальный сайт (`localhost`) видите только вы. Чтобы поделиться с другими — нужно **разместить (задеплоить)** сайт на бесплатном хостинге.

Есть 3 простых варианта. Рекомендую **Вариант 1 (Render)** — самый простой.

---

### 🥇 Вариант 1: Render.com (рекомендую новичкам)

**Плюсы:** полностью бесплатно, автоматический HTTPS, не нужно настраивать сервер, работает через GitHub.
**Минусы:** «засыпает» после 15 мин неактивности (первый заход 30–60 сек), 750 часов в месяц (хватает на 24/7 одного сайта).

#### Пошагово:

#### 5.1 Создайте аккаунт на GitHub (если нет)
1. Зайдите на **https://github.com/** → **Sign up**
2. Придумайте логин, email, пароль → Create account
3. Подтвердите email.

#### 5.2 Создайте репозиторий (хранилище кода)
1. На GitHub нажмите зелёную кнопку **New** (справа сверху) или плюсик → **New repository**
2. Repository name: `secret-santa` (или как хотите)
3. Public / Private — выбирайте **Public** (для бесплатного Render нужен публичный репо)
4. ✅ **Add a README file** — поставьте галочку
5. Нажмите **Create repository**

#### 5.3 Загрузите файлы проекта в репозиторий

**Самый простой способ — через веб-интерфейс GitHub:**
1. В созданном репозитории нажмите **Add file** → **Upload files**
2. В Проводнике откройте папку `C:\Users\WIZARD\Desktop\site`
3. **Выделите все файлы и папки** (Ctrl+A), **КРОМЕ**:
   - `node_modules/` (не загружайте — тяжелая и восстановится сама)
   - `data/santa.sqlite` (не загружайте — пусть создастся новая чистая база на сервере)
4. Перетащите выделенные файлы в окно браузера (на GitHub)
5. Внизу напишите сообщение коммита: `Initial commit` → **Commit changes**

> 💡 Файл `data/santa.sqlite` в `.gitignore` — он не загрузится случайно.

#### 5.4 Подключите Render к GitHub
1. Зайдите на **https://render.com/** → **Get Started for Free** → **Continue with GitHub**
2. Разрешите Render доступ к репозиториям (можно только к `secret-santa`).
3. В Render: **New** → **Web Service** → **Connect GitHub/GitLab**
4. Найдите свой репозиторий `secret-santa` → **Connect**
5. Render сам найдёт `render.yaml` и заполнит настройки:
   - Name: `secret-santa-pyatigorsk` (или своё)
   - Runtime: Node
   - Build Command: `echo 'No build step required'`
   - Start Command: `node server.mjs`
   - Plan: **Free**
   - Disk: Name `data`, Mount Path `/opt/render/project/src/data`, Size **1 GB**
6. Нажмите **Create Web Service**

#### 5.5 Дождитесь деплоя (2–5 минут)
- Вы увидите логи: `npm install`, затем `Secret Santa: http://localhost:10000`
- В конце появится зеленая надпись **Live** и ссылка: `https://secret-santa-pyatigorsk.onrender.com` (ваша будет другой)

#### 5.6 Готово!
- Перейдите по ссылке — сайт работает в интернете 🎉
- Регистрируйтесь, создавайте мероприятия, делитесь ссылками с друзьями.
- **HTTPS уже включён** (замочек в адресной строке).

> ⚠️ **Важно**: на бесплатном тарифе Render сайт «засыпает» после 15 минут без посещений. Первый заход после сна займёт 30–60 секунд — это нормально.

### 🥈 Вариант 2: Railway.app (не спит, работает постоянно)

**Плюсы:** не засыпает, быстрее старт, $5 бесплатных кредитов в месяц (обычно хватает).
**Минусы:** нужно добавить Volume (диск) вручную, интерфейс чуть сложнее.

1. Зайдите на **https://railway.app/** → **Login with GitHub**
2. **New Project** → **Deploy from GitHub repo** → выберите `secret-santa`
3. Railway начнёт деплой (использует `railway.json`).
4. **Важно**: после деплоя зайдите в сервис → вкладка **Volumes** → **Add Volume** → Name: `data`, Mount Path: `/app/data` → **Add**.
5. Передеплойте (Redeploy) — теперь база будет сохраняться на диске.
6. В настройках сервиса → **Networking** → **Generate Domain** → получите ссылку `https://xxx.up.railway.app`

### 🥉 Вариант 3: Oracle Cloud Free Tier (всегда бесплатно, мощный сервер)

**Плюсы:** 4 CPU, 24 GB RAM, 200 GB диск — навсегда бесплатно, не спит.

## 🔧 Частые проблемы и решения

| Проблема | Решение |
|----------|---------|
| `node` не найдена / команда не распознана | Перезагрузите компьютер после установки Node.js. Проверьте `node --version` в новом терминале. |
| `npm install` выдает ошибки | Убедитесь, что Node.js версии 22+. Попробуйте `npm cache clean --force` и снова `npm install`. |
| Сайт не открывается на `localhost:3000` | Проверьте, что в терминале написано `Secret Santa: http://localhost:3000`. Порт 3000 не занят другой программой. |
| «Сессия устарела. Обновите страницу и войдите снова.» | Просто обновите страницу (F5) и войдите снова. CSRF-токен обновляется при входе. |
| Забыл пароль / код восстановления | На странице входа нажмите «Забыли пароль?» → введите email и **код восстановления** (тот, что сохраняли при регистрации) → новый пароль. Без кода восстановить нельзя — это безопасность. |
| На Render сайт долго грузится первый раз | Это «холодный старт» после сна. Подождите 30–60 секунд. |
| На Render пропадают данные после перезапуска | Проверьте, что в Render добавлен **Disk** (Persistent Disk) с Mount Path `/opt/render/project/src/data`. Без диска SQLite хранится в памяти и пропадает. |
| Ошибка «Foreign key constraint failed» | База повреждена. Удалите `data/santa.sqlite` и перезапустите сервер — создастся чистая база. |
